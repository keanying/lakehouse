# 业务库 DDL 补齐工具

在浏览器里录入客户业务库表的 `CREATE TABLE` 语句，每次保存直接写进一个文件，不需要导出。

## 启动

- Windows：双击 `启动.bat`
- macOS / Linux：`./start.sh`
- 或：`python3 dataworks/ddl_tool/server.py`

启动后会自动打开浏览器（`http://127.0.0.1:8765/`），并自动创建 `dataworks/input/src_ddl.sql`（已存在就接着用）。工具窗口开着时页面才能保存，用完关掉窗口即可。

参数：`--file 路径` 换文件位置，`--port 端口`，`--no-browser` 不自动打开浏览器。

只依赖 Python 3 标准库。整个 `ddl_tool` 目录可以单独拷到别的电脑上用，表清单在 `src_tables.json`；在别的电脑上用时，建议加 `--file` 指定文件位置。

## 页面

- **顶栏**：处理进度，分为 DDL 一致、DDL 有差异、已弃用、未处理；写入的文件路径和最近一次保存时间；「批量粘贴 DDL」。
- **左侧表清单**：366 张业务库表。
  - 可以按状态、数据源筛选，也可以搜索表名或中文名。
  - 点「多选」后可以批量标记弃用或取消弃用。
- **批量粘贴**：一次贴多张，先预览每张对应到哪张业务库表，确认后保存。
  - 同一个表名在多个数据源都有时，在预览里逐张选择数据源。
  - 对不上的表保存为「未对上」。
- **单表**：
  - 「当前结构」：点表后先显示同步任务现在读取的字段、类型（取数仓落地表）、描述和类别，还没录 DDL 也能看；下方可展开「按现有信息拼的建表草稿」。
  - 「字段比对」：DDL 字段与同步任务读取的字段逐个比对（一致 / DDL 有、未同步 / 同步有、DDL 无），可以只看差异。
    - 表描述和每个字段的描述都可以直接改，回车跳到下一行，`Ctrl+S` 保存。
    - 「空白描述用现有注释补全」会把 DDL 里没写注释的字段，用现有描述补上；带「待确认」的推断描述不自动补。
    - 改过的描述标黄底。修改单独记在文件里，不改动客户的原 DDL，可以一键恢复 DDL 原描述。
    - 有未保存的修改时切换表会先提示。
  - 「录入 / 编辑 DDL」：粘贴时即时识别表名、字段数、主键和差异；「保存并下一张未录入」可以连续录。
  - 「标记弃用」：选原因（业务已下线 / 表已删除或迁移 / 测试或临时表 / 其他），可填备注，例如替代表名、确认人。已录入的 DDL 保留。
- **快捷键**：`/` 搜索，`↑` `↓` 切换表，`B` 批量粘贴，`Ctrl+S` 保存。

## 文件

`dataworks/input/src_ddl.sql`：
- 每张表前是标记行：`-- @table 数据源:表名`、`-- @at 录入时间`；标记弃用的还有 `-- @status 弃用`、`-- @reason 原因`、`-- @note 备注`；人工改过的描述记为 `-- @tcmt 表描述` 和 `-- @cmt 字段名 描述`。下面是原始建表语句，弃用表可以没有；
- 每次保存整份重写，上一版留在 `src_ddl.sql.bak`。

把这个文件交给数仓，重跑 `python3 dataworks/standard/build.py`。字典里的业务库字段、类型、注释、主键会以 DDL 为准；弃用的业务库表会标注出来，它对应的 ODS 也会标「建议停同步、下线」。见 `dataworks/input/README.md`。

`src_tables.json` 由 `standard/build.py` 生成。
